## New Features & Improvements

- Increased the max cap for duration and file size  for the Local market and PowerPlay data database to:

MAX_DB_SIZE_BYTES: 100MB → 350MB

- Ring Finder:Picking a specific Power now clears Contested/Expansion from the Power State filter, and picking Contested/Expansion now clears the Power filter, since those systems have no owning Power.
