# <img src="https://github.com/Viper-Dude/EliteMining/blob/main/app/Images/logo_multi.ico" width="32" height="32"> EliteMining
**Release Date:** 2026-November-20

## New Features & Improvements

- Hover the Updated column wherever prices are shown to see where each price came from.
- Sell My Hold now shows the landing pad size of each station.
- New modern look for sliders, number boxes, checkboxes and the text color and size options.
- The session summary line and the journal history import window now follow your language and theme colors.


## Bug Fixes

- General stability and code optimization: settings such as the journal folder now apply immediately, journal handling and jumps-left tracking are more reliable, and mining events are no longer missed right after startup.


### Voiceattack Profile -update to V5.6.7
- Fixed a sound effect playing even when the prospector sequence was not launched due to unmet conditions.
