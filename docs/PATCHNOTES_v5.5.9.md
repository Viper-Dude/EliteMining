## New Features & Improvements

- Ring Finder now defaults the Reserve filter to Pristine, and Reset Filters sets it back to Pristine.


### VoiceAttack Profile Update (v5.5.9)
- **Fixed:** The “Scanning for cores” command now uses continuous boost (introduced in v5.5.8).
- **Fixed:** Prevented sound events for mining commands from overlapping.
- Improved in-game cargo scoop status detection. Detection may still fail during busy moments, such as when dumping cargo or launching limpets.

### Important Notes 

- Remember to always check all your key and joystick bindings after every profile update.
