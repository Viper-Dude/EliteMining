# <img src="https://github.com/Viper-Dude/EliteMining/blob/main/app/Images/logo_multi.ico" width="32" height="32"> EliteMining
**Release Date:** 2026-November-22

## New Features & Improvements
- General code optimalization
- Hotspots Finder searches should be much faster and show results sooner.
- Mining Cards have a new slimmer look that follows your app theme and language, with all minerals in one table, the session date, cores found, and the comment you saved with the session filled in for you.
- Share to Discord now posts your Mining Card, with the system name ready to copy.
- Auto Switch now opens the Hotspots Finder after every jump, not just the first one after entering supercruise.
- Auto Prices starts looking up prices while your FSD charges, so they show up sooner when you arrive.
- The long help text under the Hotspots Finder search options is gone; the same hints are still in the tooltips.
- VoiceAttack Controls has a cleaner look; the help text beside each setting is now in its tooltip.
- Mining session - The "Prompt when full" question now appears after 15 seconds instead of a full minute. 

## Bug Fixes
- Hotspots Finder now always shows the closest rings, keeps rings already found if Spansh drops out, and no longer searches around the wrong system after a typo.
- Jumping during a Hotspots Finder search no longer changes your system name and filters, and the result count and German message are now correct.
- The app no longer freezes for a moment when you map a ring with new hotspots.

### Voiceattack Profile - update to V5.6.8
- Fixed the cargo scoop timer not starting on the first mining run. It can still fail when launching collector limpets, because each launch briefly opens and closes the cargo scoop.
