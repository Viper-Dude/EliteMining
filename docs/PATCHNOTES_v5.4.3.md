# <img src="https://github.com/Viper-Dude/EliteMining/blob/main/app/Images/logo_multi.ico" width="32" height="32"> EliteMining v5.4.3
**Release Date:** 2026-October-20

## New Features & Improvements

### Hotspots Finder

#### Find Acquisition Targets (new)
Right-click a Fortified or Stronghold mining system and choose "Find Acquisition Targets". It lists nearby Unoccupied systems with a station buying your mineral, so you know where to sell for PowerPlay Acquisition merits. Works with any mineral, including ones without hotspots like Osmium.

#### PowerPlay tick box
New "PowerPlay" tick box next to the Data Source options. It only applies to Local searches. Off (default) gives faster searches and shows only the PowerPlay info already saved on your PC. Tick it to also look up the latest PowerPlay info online.

### Mining Bookmarks
- New "Last Visited" column (first column) shows when you last were in that system. You can sort by it, and a new filter option shows systems visited in the last 30 days.
- New Mineral dropdown to show only bookmarks that contain a chosen mineral.
- New columns: distance from your current system, distance to Sol, Reserve level and number of Visits.
- New Type dropdown to filter by ring type (Metallic, Icy, Rocky, Metal Rich).
- Last Mined now updates by itself from your mining reports.
- Bookmarking from a mining report now fills in the Ring Type, and the dialog is titled "Add New Bookmark" for new bookmarks.
- The T/hr column shows the session total, and the rate for the chosen mineral when a Mineral is selected (the header changes to match). This works for bookmarks made from a mining report. Older bookmarks keep their old T/hr value. To get per-mineral rates on an older bookmark, bookmark it again from its report and choose Update.

### Mining Reports
- New "Ring Type" column next to Planet/Ring (Metallic, Icy, Rocky, Metal Rich). It stays blank if the ring isn't in your saved ring data.
- Column hover tooltips in the Reports tab now match the right column.

### Comments and Notes
Hover over a comment (Mining Reports, Ring Finder) or a note (Bookmarks) to read the full text without opening it.

### Ships
- Added Support for the new Anaconda Mk II.

### Sorting arrows
Tables now show an up or down arrow on the column you sorted by. 

### Voiceattack Profile updated to v5.4.4
- The Continuous Prospector Sequence timer now accepts decimals (e.g. 2.5 seconds).
- The Continuous timer is greyed out while Continuous Seq. is off.
- General optimisations of commands.

### Note
The documentation (README on GitHub) has not been updated for this version yet. It will be updated in the near future.
