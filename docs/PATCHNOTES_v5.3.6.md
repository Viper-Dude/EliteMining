## New Features & Improvements

- Power/Power State search on the Hotspots Finder now reaches up to 500 Ly automatically when a State is selected, using Spansh for more reliable results on several of these states.

- Added CSV export for Hotspots Finder search results - right-click the results list and choose "Export All Results to CSV" to save what's on screen to a file.

- Removed the 50-system cap on "Update Reserve Level" in the results right-click menu - update as many systems as you've selected.
