# <img src="https://github.com/Viper-Dude/EliteMining/blob/main/app/Images/logo_multi.ico" width="32" height="32"> EliteMining v5.4.4 (Hotfix)
**Release Date:** 2026-October-21

> This is a small hotfix on top of v5.4.3. If you haven't installed v5.4.3 yet, read its [full patch notes](https://github.com/Viper-Dude/EliteMining/releases/tag/5.4.3) first. This update includes everything from it.

## Hotfix

### Hotspots Finder

- **Fixed:** "Use Current System" now searches from your current system after a jump, not the previous one.

### Text Overlay

- **Fixed:** If the Cargo Monitor text overlay disappears, fully or partly, you can now bring it back by turning it off and on again. No app restart needed.
