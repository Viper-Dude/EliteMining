# <img src="https://github.com/Viper-Dude/EliteMining/blob/main/app/Images/logo_multi.ico" width="32" height="32"> EliteMining
**Release Date:** 2026-October-26

## New Features & Improvements

### Voiceattack Controls

- New Voice Feedback tab in VoiceAttack Controls with sounds for mining events such as starting and resetting the mining sequence.
- Choose a different sound set and a female or male voice for each event, or turn an event off.
- Events can now be spoken by a computer voice of your choice instead of a recorded sound.
- Test button to hear each event sound before using it.
- Volume and balance sliders for the event sounds.
- Announcement voice and volume settings moved to the top of the Announcements tab.
- Voice Feedback is a new feature, and more voices and functions will be added in future updates.

### Hotspots Finder
- Ring Finder now remembers the Spansh auto-save setting after restarting the app.

### Settings
- Moved the TTS settings from General settings tab to the Announcement tab

### Voiceattack Profile updated to v5.5.0

- Updated profile plays the new Voice Feedback event sounds set in the Voice Feedback UI
- **Fixed** the command "Prospector launch detected — scoop out of sync. Extending timer by 7 seconds" launched at every reset mining sequence even Prospector was not in stat of launch


#### Important Notes 

- Remember to always check all your key and joystick bindings after every profile update
