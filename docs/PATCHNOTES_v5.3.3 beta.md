**This is a beta release**, mainly to test the new UI Scale feature before it goes into a full release. If you run into any issues, please post them in the **#beta-testing** channel on [Discord](https://discord.gg/5dsF3UshRR).

## New Features & Improvements

- New UI Scale setting (Settings tab) — makes text and tables bigger across the whole app, great if the default size is too small to read. Choose from 100% up to 150%.


### Bug Fix

- Fixed several places where dropdowns, table columns, and status text didn't line up properly or looked squeezed — most noticeable with the new UI Scale setting, but some of these were there before too.
