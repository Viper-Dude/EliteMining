**Release Date:** 2026-October-22

## New Features & Improvements


### Discord Sharing

- **Fixed:** The Discord mining card now shows the correct Total Mined instead of only the last mineral's tons.
- **Fixed:** The time shown at the bottom of the Discord mining card is now correct for your timezone.

### Reports

- **New:** Type or paste a system name in the Reports filter to find it fast. Matching systems show up as you type.
- **New:** A summary line below the table shows sessions, total tons, average T/hr and best T/hr for the reports you are viewing.
- **New:** Right-click a report to open an existing Mining Card, or regenerate it. The Mining Card button now says Open Mining Card when one exists.


### Hotspots Finder

- **Changed:** The right-click menu is shorter, with Open in, Rank Minerals and Edit Ring Data grouped into submenus.
- **Changed:** Submenu entries now show an arrow so they are easy to spot, including Announcement Preset in the Ship Presets menu.
- **Fixed:** Save and Update Reserve Level in the multi-row right-click menu are now translated.
