**Release Date:** 2026-August-24

## New Features & Improvements


- New UI Scale setting (Settings tab) — makes text and tables bigger across the whole app, great if the default size is too small to read. Choose from 100% up to 175%. The app window now resizes to match when you change it.


### Bug Fix

- Fixed several places where dropdowns, table columns, and status text didn't line up properly or looked squeezed — most noticeable with the new UI Scale setting, but some of these were there before too.


### Voiceattack Profile no update (v5.2.5)


### Important Notes 

- Remember to always check all your key and joystick bindings after every profile update.
