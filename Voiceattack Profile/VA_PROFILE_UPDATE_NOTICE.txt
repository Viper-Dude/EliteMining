============================================================
  EliteMining v5.6.8 — VoiceAttack Profile Update 
============================================================

This release includes an updated VoiceAttack profile (v5.6.8).
What's changed:
- Fixed the cargo scoop timer not starting on the first mining run. It can still fail when launching collector limpets, because each launch briefly opens and closes the cargo scoop.

Keep the VoiceAttack profile option ticked on the next page to install the updated
profile. Follow the app's profile update instructions to import it into VoiceAttack.
After updating, please check all your key and joystick bindings.

------------------------------------------------------------
If you do NOT want to update the profile now, untick the option on the next
page. You can always re-run the installer later to update it.
------------------------------------------------------------
